# TV Tracker 2.0.1

- SLA Status and SLA Compare recognize queue deadlines that omit the year and classify countdowns using the selected capture’s report date in IST.
- SLA Compare can hide the Cancelled row from the summary matrix and its Excel export. Show Cancelled restores the row.
- Capacity Report includes a pending trend chart and a backlog breakdown. Select a point or a slice to open its order table.
- Daily Orders uses a calendar and opens matching orders from the KPI cards. Monthly Orders also opens order tables from its KPIs and supports bulk SLA changes on imported records.
- Production Report uses a lavender gradient for skipped update categories.
- Captures supports deleting individual captures or a selection. Clearing the list keeps old cloud previews from automatically returning.
